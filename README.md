# Gnosis-Exchange

Gnosis-Exchange is the planned exchange boundary for publishing, discovering, and transferring explicitly shareable Gnosis artifacts, offers, or partner opportunities.

## Intended role

- Define exchangeable artifact and offer metadata.
- Link items to their source, version, provenance, and supporting evidence.
- Keep publication and transfer separate from internal Core execution authority.
- Make the terms and boundaries of any exchange explicit.

## Trust boundary

Listing or transferring an artifact does not prove its claims, grant permission to reuse private data, or authorize execution inside Gnosis-Core. Each item needs its own applicable contract, evidence, and permission checks.

## Current status

This repository is currently a scaffold. This README records intended scope only; it does not claim that a working exchange service, API, marketplace, or transaction flow is implemented.

## Repository boundary

The separate private repository `Gnosis-Genesis` exists, but its factory, production, and authority responsibilities and deployment boundary are not confirmed by the inspected repository contents. Its name or intended role does not establish operational capability. Gnosis-Exchange does not grant authority over Gnosis-Core.

## Naming

The canonical project name is **Gnosis**. The separate private repository **Gnosis-Genesis** documents an intended factory/orchestration role; this does not by itself establish an operational end-to-end factory or execution authority.
